# SkyPro Lesson

## Описание:

Учебный проект Python. Приложение для работы с банковскими картами и счетами. В модуле main есть вызовы реализованных функций, таких как добавление масок к счетам, сортировка по статусам, корректировка даты и т. п. Проект учебный и основная цель это обучение. Функционал проекта определен учебным планом и является вторичным.

## Установка:

1. Клонируйте репозиторий:
```
  git clone https://github.com/Tutanhamon-dev/SkyProLessons.git
```
2. Установите зависимости:
```
  pip install -r requirements.txt
```
## Использование:

  Функционал в процессе написания. Запуск функций через модуль main.py в директории src
