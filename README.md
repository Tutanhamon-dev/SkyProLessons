# SkyPro Lesson

## Описание:

Учебный проект Python. Приложение для работы с банковскими картами и счетами. Реализованы функции такие, как добавление масок к счетам и номерам карт, сортировка счетов по статусу, корректировка даты и т. п. Проект учебный и основная цель это обучение. Функционал проекта определен учебным планом и является вторичным. В учебных целях добавлена папка с тестированием работы функций.

## Установка:

1. Клонируйте репозиторий:
```
  git clone https://github.com/Tutanhamon-dev/SkyProLessons.git
```
2. Установите зависимости:
```
  pip install -r requirements.txt
```
## Использование:

  Функционал в процессе написания. Запуск функций через модуль main.py в директории src
