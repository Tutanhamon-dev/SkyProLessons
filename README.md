# SkyPro Lesson

## Описание:
Учебный проект, цель которого формирование знаний, умений и навыков программирования на Python.
На данный момент написаны три модуля по две функции в каждом. Ко всем функциям написаны тесты. На данный момент покрытие тестами 100%. Линтеры flak8, mypy не выдают ошибок. В данной версии переписаны все 6 функций для обеспечения их стабильности. Добавлены перехваты ошибок. Реализованы проверки входных данных. В учебных целях в репозиторий добавлена папка tests и htmlcov.
### 1 модуль - widget.py содержит:

mask_account_card - Маскирует номер карты или счёта в строке. Принимает строку типа 'Visa Classic 6831982476737658' или 'Счет 73654108430135874305' и возвращает строку 'Visa Classic 6831 98** **** 7658' или 'Счет **4305' соответственно.

get_date - Принимает строку даты в формате '2019-07-03T18:35:29.512364' и возвращает строку в формате '03.07.2019'

### 2 модуль - processing.py содержит:

filter_by_state - Принимает список словарей и возвращает список словарей отфильтрованных по заданному ключу поля 'state'.

sort_by_date - Принимает список словарей и возвращает список словарей отсортированных по строковому полю 'date' без парсинга в datetime. Словари где нет такого поля или date задан некорректно, сохраняютя, но помещаются в конец списка.

### 3 модуль - masks.py содержит:

get_mask_card_number - Принимает числовой номер (int, float, str) и возвращает номер с маской в формате: 'XXXX XX** **** XXXX'. Номер должен быть не менее 10 и не более 100 цифр.

get_mask_account - Принимает числовой номер (int, float, str) и возвращает номер с маской в формате: '**XXXX'. Номер должен быть не менее 6 и не более 100 цифр.

### 4 модуль - generators.py содержит:
filter_by_currency - Генератор — итератор по списку с транзакциями, у которых валюта операции соответствует заданной.

transaction_descriptions - Генератор — итератор, который по очереди возвращает поле `description` каждой транзакции из списка.

card_number_generator - Генератор номеров банковских карт в формате XXXX XXXX XXXX XXXX в диапозоне от 0000 0000 0000 0001 до 9999 9999 9999 9999.

Все функции выполняют проверку входящих данных на корректность и соответствие требованиям. На данный момент код покрыт тестами на 100%.

##Тестирование.

На данный момент покрытие тестами составляет 100%. Все функции сначала тестируются с корректными входными данными. Затем проверяется их поведение при передаче им данных других типов и форматов. В ходе тестирования выявленные ошибки исправляются. TDD метод используется только тогда, когда переписать функцию быстрее, чем ее исправить.
